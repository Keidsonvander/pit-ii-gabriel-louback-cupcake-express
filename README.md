# PIT II — Cupcake Express | Gabriel Felipe dos Santos Louback

Projeto acadêmico de **Gabriel Felipe dos Santos Louback — RGM 33966117**, desenvolvido como continuidade da PIT I.

## Contexto da PIT I
A Situação-Problema 1 trata da criação de uma solução digital para uma loja de cupcakes gourmet, com foco em ampliar as vendas pela internet.

O projeto recebeu o nome **Cupcake Express** e foi planejado como um sistema web simples, responsivo e de rápida implantação.

## Funcionalidades definidas na PIT I
- vitrine virtual;
- carrinho de compras;
- alteração de quantidade e remoção de itens;
- cálculo de subtotal, taxa de entrega e total;
- dados do cliente;
- pagamento simulado;
- resumo do pedido;
- responsividade para celular e computador;
- mensagens de validação.

## Base conceitual
Foram considerados:
- levantamento de requisitos;
- histórias de usuário;
- critérios de aceitação;
- backlog priorizado;
- requisitos funcionais e não funcionais;
- regras de negócio;
- prototipação;
- mapa navegacional;
- modelagem conceitual;
- abordagem ágil com foco em MVP e iterações curtas.

## Tecnologias previstas
A PIT I definiu um protótipo em **React/Vite**, executável localmente e publicável gratuitamente.

## PIT II
Nesta etapa, a documentação é atualizada e a solução é organizada em repositório Git, mantendo coerência com o MVP desenvolvido anteriormente.

A versão demonstrativa publicada no GitHub Pages representa o fluxo principal do Cupcake Express.
